# E-Commerce Sales Dashboard

## Project Overview

This project analyzes sales performance of a small e-commerce business using Power BI and Excel.

## Tools Used

* Power BI
* Microsoft Excel
* GitHub

## Dashboard Features

* Total Revenue Card
* Total Profit Card
* Revenue by Category Chart
* Revenue Distribution Pie Chart

## Business Insights

1. Clothing products contribute significantly to revenue.
2. Footwear products generate strong profits.
3. Sales are distributed across multiple categories.

## Recommendations

1. Increase stock for high-performing categories.
2. Promote profitable products through marketing campaigns.
3. Track monthly sales trends for better planning.
